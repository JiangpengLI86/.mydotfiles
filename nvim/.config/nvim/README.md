# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Lock file note

- `lazy-lock.json` is expected and should be committed.
- It pins plugin commits so environments (native Ubuntu and WSL) install the same versions.
- This repository currently does not track a separate LuaRocks lock file.
